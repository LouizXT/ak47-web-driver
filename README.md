# Archon AK47 웹 드라이버

원본 Windows 드라이버(`DeviceDriver.exe` v1.0.0.5)의 USB 프로토콜을 역분석해 WebHID로 다시 구현한 설정 페이지입니다.
설치 없이 Chrome/Edge에서 키보드 조명·키 매핑·매크로·시스템 설정·TFT 화면을 바꿀 수 있습니다.

## 실행

WebHID는 보안 컨텍스트(`https://` 또는 `http://localhost`)에서만 동작합니다.

```powershell
node server.js
```

그 다음 Chrome 또는 Edge에서 <http://localhost:8047> 을 엽니다.

1. **키보드 연결** → 목록에서 `Archon AK47`을 선택합니다. 항목이 여러 개면 설정용(기능 리포트 64바이트)을 자동으로 고릅니다.
2. TFT 애니메이션을 올리려면 **LCD 인터페이스 추가**를 눌러 나머지 `Archon AK47` 항목도 허용합니다.
3. 개발용: 주소 뒤에 `?sim`을 붙이면 키보드 없이 화면을 둘러볼 수 있고, 보낼 패킷은 브라우저 개발자 도구 콘솔(Verbose)에 출력됩니다.

> 원본 드라이버가 실행 중이면 장치를 함께 쓰다가 충돌할 수 있으니 트레이에서 종료한 뒤 사용하세요.

## 기능

| 탭 | 내용 |
|---|---|
| 조명 모드 | 효과 19종 + 끄기, 밝기/속도/방향/색상/컬러풀 |
| 키별 조명 | 키마다 RGB 칠하기 (드래그, 전체 채우기, 스포이트), 키보드에서 읽기(실험적) |
| 키 매핑 | 기본/Fn 레이어, 키·조합키, 윈도우 단축키, 마우스, 멀티미디어/앱, 매크로, 비활성화 |
| 매크로 | 최대 100개, 키보드·마우스 녹화, 지연 편집, 저장 공간 표시 |
| 시스템 | Win/Alt+F4/Alt+Tab 잠금, Fn 전환, 절전 시간, 키 응답 속도 |
| TFT 화면 | 시계 동기화, GIF/이미지 → 240×135 RGB565 업로드 |

설정은 브라우저 localStorage에 저장되어 다음에 열어도 유지됩니다.

## 파일

- `index.html`, `css/style.css` — UI
- `js/protocol.js` — 프로토콜 (원본 함수 주소 주석 포함)
- `js/keycodes.js` — HID 키 코드, 키맵 엔트리 인코딩
- `js/layout.js` — 원본 `layouts/rgb-keyboard.xml`에서 생성한 키 배치
- `PROTOCOL.md` — 역분석한 프로토콜 정리
- `server.js` — 의존성 없는 로컬 서버

## 주의

- 실제 키보드(유선)에서 확인한 것: 시계 동기화, 조명 모드(고정·파랑), 키별 조명(LED 위치 일치). 키 매핑·매크로·시스템 설정·TFT 업로드는 아직 실기기 미확인입니다.
- 패킷은 원본 드라이버 코드와 바이트 단위로 맞췄지만, `PROTOCOL.md`에 ⚠️로 표시한 값(방향 번호, 비활성화 코드, 매크로 재생 방식, 절전 시간 번호)은 추정입니다.
- 2.4G 동글(05AC:024F)은 필터에 포함했지만 유선과 같은 프로토콜인지 확인하지 않았습니다. 유선 연결을 권장합니다.
- 공장 초기화, 펌웨어 업데이트, 실시간 음악 조명, 프로그램 실행·웹사이트 열기·텍스트 입력 같은 PC 드라이버 기능은 구현하지 않았습니다.
