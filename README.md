# Archon AK47 웹 드라이버

**👉 https://louizxt.github.io/ak47-web-driver/**

Archon AK47 키보드의 조명·키 매핑·매크로·시스템 설정을 프로그램 설치 없이 브라우저에서 바꿀 수 있습니다.
원본 Windows 드라이버(v1.0.0.5)의 통신 방식을 분석해 웹(WebHID)으로 다시 만들었습니다.

## 사용 방법

1. 키보드를 **USB 케이블로** PC에 연결합니다.
2. PC의 **Chrome** 또는 **Edge**에서 위 주소를 엽니다. (Firefox, Safari, 모바일은 지원하지 않습니다.)
3. **키보드 연결**을 누르고 목록에서 `Archon AK47`을 선택합니다. 같은 이름이 여러 개 보이면 연결될 때까지 하나씩 선택해 보세요.
4. 원하는 탭에서 설정을 바꾸고 **키보드에 적용**을 누릅니다.

한 번 허용하면 다음부터는 페이지를 열 때 자동으로 연결됩니다.
원본 드라이버 프로그램이 켜져 있으면 트레이에서 종료한 뒤 사용하는 것이 좋습니다.

## 기능

| 탭 | 내용 |
|---|---|
| 조명 모드 | 효과 19종 + 끄기, 밝기·속도·방향·색상·컬러풀 |
| 키별 조명 | 키마다 색 칠하기(드래그, 전체 채우기, 스포이트), 키보드에서 읽어오기 |
| 키 매핑 | 기본/Fn 레이어, 키·조합키, 윈도우 단축키, 마우스, 멀티미디어/앱, 매크로, 비활성화 |
| 매크로 | 최대 100개, 키보드·마우스 녹화, 지연 시간 편집 |
| 시스템 | Win / Alt+F4 / Alt+Tab 잠금, Fn 전환, 절전 시간, 키 응답 속도 |
| TFT 화면 | 시계 동기화, GIF·이미지 업로드 (240×135) |

설정 내용은 브라우저에 저장되어 다음에 열어도 그대로 남아 있습니다. 다른 PC나 다른 브라우저에서는 처음부터 다시 설정해야 합니다.

## 확인 상태

- **실제 키보드(유선)에서 확인함:** 연결, 조명 모드, 키별 조명(LED 위치 일치), 시계 동기화
- **아직 실기기 미확인:** 키 매핑, 매크로, 시스템 설정, TFT 이미지 업로드, 2.4G 동글 연결
- 일부 값(방향 번호, 키 비활성화 코드, 매크로 재생 방식, 절전 시간 번호)은 원본 드라이버 화면 순서로 추정한 값입니다. 자세한 내용은 [PROTOCOL.md](PROTOCOL.md)에 ⚠️로 표시해 두었습니다.
- 공장 초기화, 펌웨어 업데이트, 실시간 음악 조명, 프로그램 실행·웹사이트 열기·텍스트 입력처럼 PC 프로그램이 처리하는 기능은 없습니다.

## 개발

WebHID는 HTTPS 또는 `localhost`에서만 동작하므로, 코드를 고친 뒤 확인할 때는 로컬 서버로 엽니다.

```powershell
node server.js
```

- <http://localhost:8047> — 일반 실행
- <http://localhost:8047/?sim> — 키보드 없이 화면 확인 (보낼 패킷은 개발자 도구 콘솔의 Verbose 수준에 출력)

`main` 브랜치에 push하면 GitHub Pages에 1~2분 안에 반영됩니다.

| 파일 | 내용 |
|---|---|
| `index.html`, `css/style.css` | 화면 |
| `js/app.js` | 화면 동작 |
| `js/protocol.js` | 키보드 통신 (원본 함수 주소 주석 포함) |
| `js/keycodes.js` | 키 코드, 키 매핑 인코딩 |
| `js/layout.js` | 원본 `layouts/rgb-keyboard.xml`에서 생성한 키 배치 |
| `PROTOCOL.md` | 분석한 통신 프로토콜 정리 |
| `server.js` | 개발용 로컬 서버 (의존성 없음) |
