키보드를 연결하세요

Archon AK47을 USB 케이블로 PC에 연결한 다음 아래 버튼을 누르고, 목록에서 Archon AK47을 선택하세요.

이 브라우저는 키보드 연결(WebHID)을 지원하지 않습니다. PC의 Chrome 또는 Edge로 열어 주세요.

원본 드라이버 프로그램이 켜져 있다면 종료한 뒤 사용하는 것이 좋습니다.

효과

설정

방향 값 0–3은 원본 드라이버의 버튼 순서를 따른 추정값입니다. 효과마다 실제 방향이 다를 수 있습니다.

키를 클릭하거나 드래그해서 칠하세요. 적용하면 조명이 사용자 정의 모드(0x80)로 바뀝니다.

키 설정 — 키를 선택하세요

재생 방식 번호는 추정값입니다. 매크로 탭에서 매크로를 먼저 키보드에 써야 동작합니다.

“키보드에 쓰기”를 눌러야 실제로 저장됩니다. Fn 레이어에서 회색 키는 Fn 기본 기능이 있어 바꿀 수 없습니다.
